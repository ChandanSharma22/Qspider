**constraints**  

These are the rules given in the column to validate the data

&#x20;

types of **constraints**

1. **Unique** 
2. **not null**
3. **check**
4. **primary key**
5. **Foreign key** 
6. **default**



1. **unique:** 

   1. it is used to avoid duplicate or repeated values enter into the column 
   2. Not null: it is used to avoid null values entered into the column

**2. Check:**

&#x20;  1. Check is used along with the condition. If the condition is satisfied, it will accept the value else it will reject the value 

**4. primary key:** 
   1. A primary key is a constraint that is used to uniquely identify the records in the table



**Characteristics of a primary key**

1. it will not accept duplicate or repeated values.
2. it will not accept a null value
3. A primary key is a combination of unique and not null.
4. There should be only one primary key inside the table 



**Foreign key** 

it is used to establish the connection between multiple tables.



**Characteristics** 

1.it will accept duplicate or repeated values.

2\. it will accept a null value 

3\. it is not a combination of unique and not null

4\. For a column to become a foreign key, first it should be the primary key of its own table  

5\. Forging key belongs to the parent table but says in the child table to establish a connection between them.

6\. Forging key, also known as Reparent integrity constraint  





**Default** 

it is a constraint that is used to give default values 

Syntax: DEFAULT(VALUE)

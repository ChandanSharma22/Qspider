*DBMS*
1. DBMS stands for database management system 
2. It's a software that is used to maintain and manage the database 
3. DBMS provides two important features
     1. Security 
     2. authorization (ex: OTP)
4. DBMS stores data in a file format.
5. DBMS uses a query language to communicate with the database 

----------------------------------------------------------------------------

*RDBMS*

1. RDMS stands for relational database management system 
2. It is software that is used to maintain and manage the database 
3. RDBMS  provides two important features
     1. Security 
     2. authorization (ex: OTP)
4. RDBMS stores data in a table format 
5. RDMS uses a Structured Query Language to communicate with the database 

----------------------------------------------------------------------------
